How to use this checklist
  1. Log in with the role shown on the right of each section heading (on the live site or the Android app).
  2. Do what the What to check column says and compare with Expected result.
  3. Tick OK when it works exactly as written, or Issue when anything differs, and write what happened in Remarks.
  4. Points marked ⚠ are already known issues (listed in BUGS.md, 33 points). Show them to the client as known and note the agreed fix date.

☐ OK = works as expected   ·   ☐ Issue = does not work / differs (write details in Remarks)
